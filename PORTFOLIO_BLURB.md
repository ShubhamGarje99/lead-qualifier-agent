# Portfolio entry

**Title:** AI Lead Qualifier Agent with Human Approval (LangGraph + Claude + FastAPI)

**Description (3 lines):**
A production-style LangGraph agent that enriches inbound leads from their website, scores them against a
configurable ICP rubric and drafts a personalised reply. It then pauses for human approval before writing to the
CRM and Slack. Durable SQLite checkpoints, retries, idempotent HMAC-signed webhooks, per-lead cost tracking, and an
eval suite with a confusion matrix and an LLM judge.
